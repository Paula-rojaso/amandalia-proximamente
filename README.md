# Amandalia Pet Store — Próximamente

Landing temporal lista para Vercel. Sube esta carpeta como proyecto estático.

Antes de publicar, puedes editar en `index.html`:

- El nombre y los textos visibles.
- El botón de correo (ventas@amandaliapetstore.com) y WhatsApp (+56 9 4100 4600).
- Dirección: Galaxia Sur 0857, Maipú, Región Metropolitana de Santiago, Chile.
- El logo original se incluye en logo-amandalia.png; mantenlo junto a index.html.
- Los colores al comienzo del bloque CSS.

Proyecto estático sin compilación. Puedes importarlo a Vercel mediante un repositorio o publicarlo con su CLI. No se ha publicado todavía. Antes de conectar el dominio, confirma el nombre exacto y utiliza los registros DNS que indique el proveedor. Conserva todos los registros de correo, incluidos MX y TXT.

Al publicar la tienda de Jumpseller, cambia los registros web del dominio a los que indique Jumpseller. Así Vercel deja de mostrar esta página y aparece la tienda.
